# Atrium Europe 🇪🇺

> "Europe isn't lacking talent; it’s just lacking a map. Atrium is that map."

---

##  The Heart of the Project
I built **Atrium Europe** because the innovation landscape in Europe is vast but fragmented. There are brilliant minds in Lisbon, developers in Berlin, and creators in Paris—but finding the right stage to compete and build is often harder than the building itself.

Atrium is a curated ecosystem. It’s a central "hub" where hackathons, buildathons, and innovation challenges are gathered into one place. My goal was to build a platform that allows the best talent to find the best opportunities without the noise.

---

## Architectural Philosophy
In building Atrium, I prioritized **Discoverability** and **Scalability**. The goal wasn't just to make a list, but to create an infrastructure that could handle the rapid pulse of the European tech scene.

* **Product Velocity:** By utilizing modern orchestration tools (like Cursor and v0), I was able to bypass the "plumbing" of the project and focus 100% on the **User Journey** and **SEO Strategy**.
* **SEO as a Feature:** I integrated **JSON-LD structured data** to ensure that these innovation opportunities aren't just visible on Atrium, but are indexed properly across the web to reach the widest possible audience.

---

## The Tech Stack
* **Frontend:** React + TypeScript + Vite (Selected for raw performance and DX)
* **Styling:** Tailwind CSS + Radix UI (A modular, accessible design system)
* **Backend:** Supabase (Real-time data integrity for live event updates)
* **Data:** JSON-LD / SEO Optimization (Engineered for maximum reach)
